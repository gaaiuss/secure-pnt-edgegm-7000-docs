### SecurePNT EdgeGM 7000 - Access Guide

---

#### Connection via serial (Console)

Putty:

COM4 (or access device manager to check the correct entry)

- 115200 baud
- 8 data bits
- 1 stop bit
- No parity
- None (flow control)

Default username:

```sh
viavi02
```

Default password:

```sh
25g#EGM7@@@
```
